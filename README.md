# 📊 Zomato Data Analysis Project

## 🔹 Project Overview
This project analyzes Zomato restaurant data to extract meaningful business insights related to pricing, customer ratings, and service availability.
The goal is to understand restaurant distribution, customer behavior, and key operational trends that can support data-driven decision-making.

## 🔹 Dataset Information
- Source: Zomato dataset (cleaned using Excel)
- Total Records: ~9551 restaurants
- Key Fields: Restaurant ID, City, Country, Rating, Price Range, Online Delivery, Table Booking

## 🔹 Tools & Technologies Used
- Excel → Data Cleaning & Preprocessing (Power Query)
- SQL → Data Analysis (JOIN, GROUP BY, CASE WHEN, Aggregations)
- Power BI → Dashboard & Data Visualization

## 🔹 Key KPIs
- Total Restaurants: 9551  
- Average Rating: ~2.5  
- Online Delivery Availability: ~25%  
- Table Booking Availability: ~12%  

## 🔹 Key Analysis Performed

### 1. Restaurant Distribution
- Analyzed restaurant count by city and country using SQL JOIN
- Identified top-performing cities with highest restaurant concentration

### 2. Price Segmentation
- Classified restaurants into Low, Medium, High categories using CASE WHEN
- Found that low-cost restaurants dominate the dataset

### 3. Customer Ratings Analysis
- Grouped restaurants by rating range
- Observed that most restaurants fall into mid-rating categories

### 4. Service Availability
- Calculated percentage of restaurants offering:
  - Online delivery
  - Table booking
- Found low adoption of table booking compared to delivery

### 5. Time-Based Trends
- Analyzed restaurant growth over years
- Identified fluctuations in restaurant openings

## 🔹 Dashboard (Power BI)
The interactive dashboard includes:
- KPI Cards (Total Restaurants, Avg Rating, Delivery %, Booking %)
- Price Distribution Chart
- Rating Distribution Chart
- City-wise Restaurant Analysis
- Time Trend Analysis
- Service Availability Charts

## 🔹 Key Insights
- Majority of restaurants fall under low-price category
- Average ratings are relatively low (~2.5), indicating improvement opportunities
- Online delivery is adopted more than table booking
- Restaurant distribution is heavily concentrated in major cities
- Growth trend shows inconsistent expansion over years

## 🔹 Files Included
- Zomato Cleaned Dataset (.xlsx)
- SQL Analysis File (.sql)
- Power BI Dashboard (.pbix)
- Project Presentation (.pptx)

## 🔹 Conclusion
This project demonstrates end-to-end data analysis, starting from data cleaning to business insights and dashboard creation. It highlights practical skills in SQL, Excel, and Power BI for real-world data analysis scenarios.
